# Raw assets

Everything in this folder except this README is gitignored. Raw asset files must never be committed.

## What goes here

Copy the whole pack folder here, keeping its original structure:

```
assets/source/kenney_monster-builder-pack/
  License.txt
  PNG/Default/   body_*, arm_*, leg_*, eye_*, mouth*, nose_*, detail_*, ...
  PNG/Double/    the same parts at twice the size
```
